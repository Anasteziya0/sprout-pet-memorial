# 🐾 EcoPet Planner (BioCycle Pet Planner)

> Веб-платформа полного цикла для экспертного планирования экологичного увековечивания памяти домашних животных, расчета параметров биодеградации и трекинга роста растений.

---

## 🚀 О проекте

**EcoPet Planner** — это экспертно-аналитическая система, которая помогает владельцам питомцев экологично и цивилизованно подойти к вопросу памяти. Платформа рассчитывает оптимальный тип био-капсулы и подбирает саженцы под конкретный регион, почву и климатическую зону, а также предоставляет инструменты для ведения долгосрочного дневника ухода за деревом.

### 📌 Ключевые возможности:
* **Экспертный калькулятор:** Автоматический расчет сроков биодеградации капсулы на основе массы животного, типа почвы и климатической зоны.
* **Генерация PDF-паспортов:** Создание персонального документа посадки с уникальным QR-кодом и инструкцией по уходу.
* **Интерактивная карта:** Поиск разрешенных эко-зон, мемориальных лесов и парков для высадки.
* **Личный кабинет и Трекер роста:** Приватный дневник для отслеживания развития дерева с возможностью загрузки сезонных фото и заметок.

---

## 🛠️ Технологический стек

* **Frontend:** React, Vite, Tailwind CSS, Leaflet.js (картография)
* **Backend:** Django REST Framework, SimpleJWT (авторизация)
* **Database:** PostgreSQL

---

## 📐 Архитектура и структура БД

* **Основные сущности:** `User` (Пользователи), `Pet` (Питомцы), `EcoMaterial` (Материалы капсул), `Plant` (Растения/Саженцы), `EcoZone` (Эко-парки), `Calculation` (Расчеты и паспорта), `TreeLog` (Дневник роста).
* **Архитектурный паттерн:** Client-Server (SPA + REST API).
